# Security Policy

This repository ships knowledge and reference examples, not runnable products. Its
purpose is to teach safe low-level engineering — several `examples/bad/` snippets are
intentionally vulnerable to illustrate a bug class, and must never be copied into
production code.

## Reporting an issue

If you find an error, an unsafe recommendation, or an incorrect claim in any skill:

1. Open a GitHub issue with the skill path and the specific claim.
2. Include the primary source or a reproduction that contradicts it.

Do not use this issue tracker to report vulnerabilities in third-party software —
report those to the respective upstream projects instead.

## Scope

- **In-scope:** incorrect or unsafe guidance in `skills/`, `references/`, `examples/`, `evals/`.
- **Out-of-scope:** vulnerabilities in toolchains, third-party libraries, or upstream projects.
